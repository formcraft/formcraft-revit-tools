Seven script rules
Dry-run input, one transaction, CSV log, fail loudly, master-data fields only, versioned in Git, re-tested after upgrades (MAN 17.2).
Approved only
Testing scripts can run on the pilot model, never on a live project.
First run is a dry run
On any model a script hasn't touched before, the first run only plans and logs.
Stop the chain
If a step fails, the chain stops and says why. Later steps never run on a half-done model.
